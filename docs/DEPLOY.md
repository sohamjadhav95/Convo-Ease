# Deploying ConvoEase for free

This guide puts ConvoEase on the internet using only free plans. You need three things:

| Part | What it does | Recommended free option |
|---|---|---|
| **App server** | Runs the Python app and serves the website | [Render](https://render.com) |
| **Database** | Keeps users, groups, messages, images and voice notes | [Neon](https://neon.tech) (Postgres) |
| **AI** | Moderates text, images and audio | [Google Gemini API](https://aistudio.google.com/apikey) |

None of these ask for a credit card on their free plans (at the time of writing).

> **Why a separate database?** Free app hosts wipe their disk every time the app
> restarts or redeploys. If the data lived on that disk, everything would vanish.
> Neon keeps it safe.

---

## Step 1 — Get a Gemini API key (2 minutes)

1. Open <https://aistudio.google.com/apikey> and sign in with a Google account.
2. Click **Create API key** and copy it. Keep it private.

## Step 2 — Create the database (3 minutes)

1. Sign up at <https://neon.tech> and create a project (any name, pick the region closest to your users).
2. On the project dashboard click **Connect** and copy the connection string. It looks like:
   `postgresql://user:password@ep-something.aws.neon.tech/neondb?sslmode=require`

Already have a Vercel account? You can create the same free Neon database there instead:
Vercel dashboard → **Storage** → **Create Database** → **Neon** → Free plan. Then copy the
`DATABASE_URL` value it shows (any of the Postgres URLs work).

ConvoEase creates its tables by itself on first start. Nothing else to do here.

> Vercel itself is not a good home for the app: its functions limit uploads to 4.5 MB
> and cut long AI calls short. Use it for the database only, and run the app on Render.

## Step 3 — Deploy the app on Render (5 minutes)

1. Make sure the code is on GitHub (it already is).
2. Sign up at <https://render.com> with your GitHub account.
3. Click **New → Blueprint**, choose the `Convo-Ease` repository, and pick the branch you want to deploy.
   Render reads `render.yaml` from the repo and sets everything up.
4. It asks for two values:
   - `GEMINI_API_KEY` → the key from step 1
   - `DATABASE_URL` → the connection string from step 2
5. Click **Apply**. The first build takes a few minutes.
6. Open the `https://convoease-xxxx.onrender.com` link Render shows you. Create an account and start chatting.

The secret key for login cookies (`CONVOEASE_SECRET_KEY`) is generated by Render automatically.

### Things to know about the free plans

- **Render** puts the app to sleep after 15 minutes with no visitors. The next visit wakes it up, which takes about a minute. After that it is fast again.
- **Neon** free plan includes about 0.5–1 GB of storage per project. That is plenty for text, but images and voice notes are stored there too, so very heavy media use will fill it eventually.
- **Gemini** free plan has per-minute and per-day request limits (shown in Google AI Studio). Every text message is one AI request; images use two; voice notes use three. If the limit is hit, users see "moderation is temporarily unavailable" and can retry a minute later. The app also limits how fast one person can send (30 messages / 10 uploads per minute) to protect your quota.

## Step 4 (optional) — Bring over your old data

If you used ConvoEase v4 (the CSV files in `database/Databases/`), copy that data into the new database once, from your own computer:

```bash
pip install -r requirements.txt
# Windows PowerShell:  $env:DATABASE_URL="postgresql://...your Neon URL..."
# macOS / Linux:       export DATABASE_URL="postgresql://...your Neon URL..."
python scripts/import_legacy_csv.py --utc-offset +05:30
```

`--utc-offset` is the time zone the old messages were written in (`+05:30` is India).
Running it twice is safe; it skips anything already imported. Old passwords keep working.

## Other free hosting options

All of these work with the included `Dockerfile`. Use Neon for the database with any of them.

| Host | Good for | Notes |
|---|---|---|
| **Hugging Face Spaces** | More power (2 CPU, 16 GB RAM free) | Create a Space → SDK: **Docker** → push this repo. Add `GEMINI_API_KEY`, `DATABASE_URL`, `CONVOEASE_SECRET_KEY` under *Settings → Variables and secrets*. Sleeps after 48 hours without visitors. The app listens on port 7860, which is what Spaces expects. |
| **Koyeb** | Always-on small apps | One small free instance. Deploy from GitHub with the Dockerfile. May ask for a card at sign-up. |
| **Google Cloud Run** | Scaling to many users | Very generous free usage, but needs a billing account (card) to start. |
| **Oracle Cloud Always Free** | Running AI models yourself | A real virtual machine (up to 4 CPU / 24 GB RAM) that can even run local models, but you manage the Linux server yourself and a card is required. |

Free-tier rules change often. Check each provider's pricing page before relying on these numbers.

## Switching the AI provider

Gemini is the default. To use something else, set these on your host instead of `GEMINI_API_KEY`:

| Provider | Variables |
|---|---|
| Groq (free, very fast) | `CONVOEASE_AI_PROVIDER=groq`, `GROQ_API_KEY=...` |
| NVIDIA NIM | `CONVOEASE_AI_PROVIDER=nvidia`, `NVIDIA_API_KEY=...`, plus `CONVOEASE_AUDIO_PROVIDER=gemini` and `GEMINI_API_KEY` for voice notes (NVIDIA has no speech API) |
| Anything OpenAI-compatible (OpenRouter, OpenAI, Ollama...) | `CONVOEASE_AI_PROVIDER=custom`, `CONVOEASE_API_URL`, `CONVOEASE_API_KEY`, `CONVOEASE_TEXT_MODEL_ID`, `CONVOEASE_IMAGE_MODEL_ID`, `CONVOEASE_AUDIO_MODEL_ID` |

You can also change only the models, e.g. `CONVOEASE_TEXT_MODEL_ID=gemini-3.6-flash`.

## All settings

| Variable | Default | Meaning |
|---|---|---|
| `CONVOEASE_ENV` | `development` | Set to `production` on a server (turns off debug, requires a secret key, secure cookies). |
| `CONVOEASE_SECRET_KEY` | — | Signs login cookies. Required in production. Generate: `python -c "import secrets; print(secrets.token_hex(32))"` |
| `DATABASE_URL` | local SQLite file | Postgres connection string. |
| `GEMINI_API_KEY` | — | Google Gemini key. |
| `CONVOEASE_AI_PROVIDER` | picked from whichever key is set | `gemini`, `groq`, `nvidia` or `custom`. |
| `CONVOEASE_TEXT_MODEL_ID` / `_IMAGE_` / `_AUDIO_` | provider defaults | Override a model. |
| `CONVOEASE_MAX_IMAGE_MB` / `CONVOEASE_MAX_AUDIO_MB` | `8` / `10` | Upload size limits. |
| `CONVOEASE_RATE_LIMITS` | `true` | Per-user request limits. |
| `PORT` | `5000` (`7860` in Docker) | Port to listen on. Most hosts set this for you. |
| `WEB_CONCURRENCY` | `2` | Number of server processes (use `1` on 512 MB plans). |

## Checking that it works

- `https://your-app/healthz` shows `"database": "ok"` and whether each AI feature is `ready`.
- If an AI feature says `unavailable`, the host's logs say why (usually a missing or wrong API key).
